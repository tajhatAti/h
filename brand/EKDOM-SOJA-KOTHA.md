# একদম সোজা কথা — ৬টা স্টেপ

আগের ফাইল দুইটা ভুলে যাও। শুধু এইটা করো।

---

## প্রথমে বুঝে নাও ব্যাপারটা কী (৩০ সেকেন্ড)

তোমার সাইটের ঠিকানা এখন:

```
ahadorg.onrender.com
```

তুমি চাও এইটা:

```
codenest.is-a.dev
```

`is-a.dev` একটা ফ্রি সার্ভিস। তারা ডেভেলপারদের ফ্রিতে নাম দেয়।

**নাম পাওয়ার একটাই নিয়ম:** GitHub-এ ওদের কাছে একটা ছোট ফাইল পাঠাতে হবে। ওরা দেখে "ঠিক আছে" বললে নামটা তোমার।

**এখন তোমার অবস্থা:** তুমি ফাইলটা এখনো পাঠাওনি।
তাই Render বলছে *"We weren't able to verify"* — মানে **"নামটা তো এখনো তোমার না"**।

**তাই এখন একটাই কাজ — ফাইলটা পাঠানো।** নিচে ৬টা স্টেপ।

---

## 🟢 স্টেপ ১

ব্রাউজারে এই লিংকে যাও:

```
https://github.com/is-a-dev/register
```

উপরে **ডান দিকে** একটা বাটন আছে — **`Fork`**

সেটায় ক্লিক করো। তারপর সবুজ **`Create fork`** বাটনে ক্লিক করো।

৫ সেকেন্ড অপেক্ষা করো।

> **Fork মানে কী?** ওদের ফোল্ডারের একটা কপি তোমার অ্যাকাউন্টে চলে আসল। এখন তুমি এই কপিতে যা খুশি করতে পারবে।

✅ হয়ে গেলে স্টেপ ২

---

## 🟢 স্টেপ ২

এখন তুমি তোমার নিজের কপির ভিতরে আছ।

পেজে ফাইল-ফোল্ডারের একটা লিস্ট দেখবে। সেখানে **`domains`** নামে একটা ফোল্ডার খুঁজে বের করো।

**`domains`** লেখাটায় ক্লিক করো।

✅ হয়ে গেলে স্টেপ ৩

---

## 🟢 স্টেপ ৩

এখন উপরে ডান দিকে দেখো — **`Add file`** নামে একটা বাটন।

ক্লিক করো → একটা ছোট মেনু নামবে → **`Create new file`** বেছে নাও।

✅ হয়ে গেলে স্টেপ ৪

---

## 🟢 স্টেপ ৪

উপরে একটা খালি বক্স দেখবে, ফাইলের নাম লেখার জন্য।

ওখানে হুবহু এইটা লিখো:

```
codenest.json
```

> ছোট হাতের অক্ষর। কোনো স্পেস না। শেষে `.json` অবশ্যই।

তার নিচে বড় খালি জায়গাটায় এইটা **কপি করে পেস্ট** করো:

```json
{
    "owner": {
        "username": "tajhatAti"
    },
    "records": {
        "CNAME": "ahadorg.onrender.com"
    }
}
```

> ⚠️ `tajhatAti` — এইটা তোমার GitHub username, আমি তোমার রিপো দেখে নিয়েছি।
> যদি অন্য অ্যাকাউন্ট দিয়ে করো, তাহলে ওই নামটা বসাও।
>
> বাকি কিচ্ছু বদলাবে না। একটা অক্ষরও না।

✅ হয়ে গেলে স্টেপ ৫

---

## 🟢 স্টেপ ৫

পেজের নিচে স্ক্রল করো। সবুজ **`Commit changes`** বাটন দেখবে।

ক্লিক করো → একটা বক্স আসবে → আবার সবুজ **`Commit changes`** বাটনে ক্লিক করো।

> **Commit মানে কী?** ফাইলটা সেভ হলো।

✅ হয়ে গেলে স্টেপ ৬

---

## 🟢 স্টেপ ৬ (শেষ স্টেপ)

এখন উপরে একটা **হলুদ ব্যানার** দেখবে, তাতে লেখা:

**`Compare & pull request`**

ওই বাটনে ক্লিক করো।

একটা নতুন পেজ আসবে। সেখানে দুইটা বক্স:

**উপরের বক্সে (Title) লিখো:**
```
Register codenest.is-a.dev
```

**নিচের বড় বক্সে (Description) এইটা পেস্ট করো:**
```
CodeNest is a free hosting platform for Telegram bots.

Users paste their Python or Node.js code in a browser editor and their
bot runs 24/7 with live logs, environment variables and auto-restart.

It is made for beginner developers who cannot afford a VPS or a credit
card for paid hosting.

Currently hosted on Render at ahadorg.onrender.com
```

**তারপর একটা স্ক্রিনশট দাও:**
- তোমার সাইট `ahadorg.onrender.com` খোলো
- একটা স্ক্রিনশট নাও
- ওই ছবিটা মাউস দিয়ে টেনে এনে Description বক্সের ভিতরে ছেড়ে দাও

> **স্ক্রিনশট দিতেই হবে।** ওদের নিয়মে লেখা আছে। না দিলে ওরা reject করতে পারে।

যদি নিচে কিছু **চেকবক্স** থাকে — সবগুলোতে টিক দিয়ে দাও।

সবশেষে সবুজ **`Create pull request`** বাটনে ক্লিক করো।

# 🎉 শেষ!

## এখন কী?

**এখন তোমার কাজ শেষ। শুধু অপেক্ষা।**

is-a.dev-এর লোকজন ভলান্টিয়ার — ফ্রিতে সময় দিয়ে কাজটা করে। তোমার ফাইলটা দেখে ওরা "হ্যাঁ" বলবে।

⏱️ **সময় লাগতে পারে কয়েক ঘণ্টা থেকে কয়েক দিন।**

এর মধ্যে:

| করবে | করবে না |
|---|---|
| ✅ Render-এ ডোমেইনটা যেমন আছে রেখে দাও | ❌ Render থেকে ডোমেইনটা মুছে ফেলবে না |
| ✅ ধৈর্য ধরো | ❌ বারবার `Verify` চাপবে না, লাভ নাই |
| | ❌ ওদের কাউকে মেসেজ দেবে না — দিলে উল্টো দেরি হবে |

## হয়ে গেছে কিনা কিভাবে বুঝবে

দিনে একবার এই লিংকে যাও:

```
https://github.com/is-a-dev/register/blob/main/domains/codenest.json
```

| যা দেখবে | মানে |
|---|---|
| **404 Not Found** | এখনো হয়নি। কাল আবার দেখো। |
| **তোমার ফাইলটা দেখাচ্ছে** | 🎉 **হয়ে গেছে!** নিচে দেখো |

---

## হয়ে যাওয়ার পর — আর মাত্র ২টা কাজ

### কাজ ১ — Render-এ গিয়ে Verify চাপো

- ১ ঘণ্টা অপেক্ষা করো (নামটা সারা দুনিয়ায় ছড়াতে সময় লাগে)
- Render → `ahadorg` → **Settings** → **Custom Domains**
- **`Verify`** বাটনে ক্লিক করো
- সবুজ লেখা আসলে হয়ে গেছে ✅

এখন `https://codenest.is-a.dev` খুলে দেখো — তোমার সাইট চলে আসবে।

### কাজ ২ — ⚠️ এইটা ভুললে লগইন বন্ধ হয়ে যাবে

Telegram-এ **@BotFather** খোলো। এই তিনটা মেসেজ পাঠাও:

```
/setdomain
```
→ ও তোমার বটের লিস্ট দেখাবে, তোমার বটটা বেছে নাও

→ তারপর লিখো:
```
codenest.is-a.dev
```

**কেন?** Telegram-এর লগইন বাটন শুধু একটা নির্দিষ্ট ঠিকানায় কাজ করে। নতুন ঠিকানা না বললে লগইন বাটন **কোনো এরর ছাড়াই চুপচাপ কাজ করা বন্ধ** করে দেবে।
