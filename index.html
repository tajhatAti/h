HOW IT WORKS

Three steps, about a minute

  1. 1

    Paste your code

    Bring the bot you already wrote. No rewriting, no proprietary framework, no config file.

  2. 2

    Press deploy

    CodeNest reads your imports, installs what is missing, and starts the process.

  3. 3

    It stays up

    Crashed at 3am? It restarts itself. Watch live logs and stop or redeploy whenever you want.

WHAT YOU GET

Built for people who ship bots

Always-on hosting

Long-running processes, not request handlers. Pollers, schedulers and workers stay alive between messages.

Automatic restarts

A crash is not an outage. The supervisor brings your process back and records what happened in the log.

Dependencies handled

Imports are detected and installed on deploy. No requirements file to maintain by hand.

Live logs

Stream stdout as it happens, so you can debug a running bot without SSH or a log service.

Public URLs

Bind a web server to $PORT and get a free HTTPS link — useful for webhooks and dashboards.

Your code stays yours

Plain Python, Node, Bash, Ruby or PHP. Download it, move it elsewhere, stop any time.

Python and Node libraries install automatically from your imports. System packages cannot be installed per job — RunSpace is shared, so one job changing the container would affect everyone. Need another tool? Ask on the Telegram channel and it can be added to the image.
